## 0.4.1 — 2026-08-19

> **Upgrade note — Merino now requires herdr 0.8.2 (protocol 20).** herdr 0.8.2
> bumped the socket protocol from 19 to 20, and older Merino refused the new
> protocol — the dashboard showed a disconnected herd with no agents after the

## 0.4.0 — 2026-08-07

> **Upgrade note — optional GitHub / Keycloak sign-in.** The dashboard can now
> admit people over GitHub or Keycloak (OIDC), on top of password / QR login.
> It ships off: nothing changes until you configure a provider under
> **Settings → Access → Single sign-on** (or an `oauth:` block in `config.yml`)
> and set an admission rule (an allowlist, org/team, or realm role). OAuth needs
> a public HTTPS origin, so set `publicUrl` and register
> `<publicUrl>/login/github/callback` (or `/login/oidc/callback`) with the
> provider. The client secret lives in a `clientSecretFile` or env, never in
> `config.yml`; `clientID` is the app's Client ID, not the secret.

### Added

- **web** — Add GitHub and Keycloak OAuth login (#40)
- **web** — Configure OAuth sign-in from Settings (browser + menubar) (#41)
- **web** — Collapse single sign-on settings by default (#42)
- **config** — Configure OAuth from config.yml + open-config button (#43)

### Fixed

## 0.3.1 — 2026-08-02

> **Upgrade note — a paired phone could mint more pairings.** Every release
> up to and including 0.3.0 accepted `/api/pairing/mint` from any signed-in
> caller, and a paired phone is signed in. It could issue itself successors,
> so revoking a lost phone did not necessarily end its access. The route now
> refuses device sessions, matching every other device-management route and
> what `/api/session` has always reported. If a phone has been lost or a
> device you do not recognise appears, revoke under **Settings → Pairing**
> after upgrading, not before. Pairing needs an operator, so a phone cannot
> quietly reinstate itself.
>
> Headless can pair now: **Settings → Pairing** in the browser, or
> `merinod qr` for a code drawn in the terminal.

### Added

- **pairing** — Let the headless dashboard mint a QR, and stop phones minting (#22)
- **merinod** — Merinod qr draws a pairing QR in the terminal (#23)



## 0.3.0 — 2026-08-02

> **Upgrade note — nothing changes for the menu bar app.** This release adds
> `merinod`, the same dashboard without the menu bar, for Linux servers; the
> macOS app keeps its state exactly where it was, so no phone is unpaired.
> If you tried `v0.3.0-rc.1` on Linux, its state directory was wrong — a
> `Library/Logs` folder in `$HOME`, or a boot failure in a container. State
> now follows `XDG_STATE_HOME`, so re-pair once and delete the stray folder.

## 0.2.0 — 2026-07-29
